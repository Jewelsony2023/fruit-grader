How a prediction is made

  1. Shared backbone. A pretrained CNN (EfficientNet-B0 / ResNet-50 / MobileNetV3) turns the image into feature maps.
  2. Three heads, trained together. Grade classifier (A / B / C / Reject), U-Net decoder for a pixel mask (healthy, bruise, rot, mechanical damage), and a severity regressor (0–100).
  3. Severity. Damaged pixels ÷ fruit pixels × 100, from the mask, so the number can be checked by eye. The regression head gives a second estimate.
  4. Grad-CAM. Shows which pixels pushed the model to its grade. If it lights up the background, don't trust the result.
  5. MC Dropout. The grade head runs 20 times with dropout on. Big disagreement or low confidence flags the fruit for manual review.
  6. Consistency check. The grade the classifier picks is compared to the grade the defect area implies (rules below). A mismatch is also flagged.
